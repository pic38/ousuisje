Ochrana soukromí

Co se odesílá, komu a v jakém případě.

Obecný princip

OuSuisJe nemá vlastní aplikační server: žádná data o poloze se neshromažďují, neukládají ani neodesílají na server OuSuisJe. Žádost o povolení geolokace zpracovává přímo váš prohlížeč.

GPS lokalizace

Zpracování vaší polohy (souřadnice, nadmořská výška, rychlost, kurz, přesnost) probíhá zcela lokálně, na vašem zařízení. Nic se nikam neodesílá. Tato funkce funguje offline i po přidání webu na plochu.

Adresa (reverzní geokódování)

Když požádáte o vyhledání adresy, souřadnice zvoleného bodu (GPS poloha nebo bod kliknutý na mapě) se odesílají přímo z vašeho prohlížeče službě Nominatim OpenStreetMap, bez průchodu serverem OuSuisJe. Tato funkce nefunguje offline.

Nadmořská výška

Porovnání nadmořské výšky stejným způsobem odesílá pouze souřadnice zvoleného bodu — službě géoplateforme IGN (pokud je vaše poloha zjištěna ve Francii) nebo Open-Elevation (kdekoli jinde), podle použitého tlačítka. Nefunguje offline.

Zajímavá místa

Vyhledávání zajímavých míst v okolí (stravovací zařízení, vlastní sekce…) odesílá souřadnice aktivního bodu rozhraní API Overpass OpenStreetMap. Nefunguje offline.

Departement, obec a vysílače

Tyto funkce se objevují pouze tehdy, je-li vaše poloha zjištěna ve Francii. Opírají se o datové sady (IGN Admin Express, ANFR) stažené jednou z vlastního hostingu OuSuisJe a poté uložené ve vašem zařízení. Následný výpočet (ve kterém departementu/obci se nacházíte, které vysílače jsou poblíž) pak probíhá zcela lokálně, bez jakéhokoli odesílání vašich souřadnic komukoli. Funguje offline po dokončení stahování.

Pitná voda a toalety

Datová sada (body pitné vody a toalet ve Francii, zdroj OpenStreetMap) se automaticky stahuje při prvním načtení stránky, vždy z hostingu OuSuisJe. Vyhledávání pak probíhá lokálně, bez odesílání souřadnic. Pokud toto stahování selže nebo jej odstraníte, vyhledávání se automaticky vrátí k živému API Overpass (za stejných podmínek jako sekce „Zajímavá místa“ výše).

Srážkový radar

Zobrazení radaru žádá RainViewer o snímky odpovídající oblasti aktuálně zobrazené na mapě (souřadnice a úroveň přiblížení zobrazení, nikoli vaše GPS poloha). Nefunguje offline.

Počítadlo návštěv

Anonymní a agregované počítadlo návštěv (bez jakýchkoli osobně identifikovatelných údajů) se zaznamenává u třetí strany při každém načtení stránky.

Sdílení

Tlačítko sdílení používá nativní sdílecí nástroj vašeho zařízení, nebo jednoduše zkopíruje odkaz na web do schránky. Při tom se OuSuisJe žádná data nepřenášejí.

Aplikace pro Android

OuSuisJe existuje také jako samostatná aplikace pro Android. Platí zde stejné zásady: žádný vlastní aplikační server OuSuisJe a každá funkce, která opouští zařízení, tak činí přímo ke příslušné službě třetí strany, podle stejných pravidel jako výše.

Stručně: každá funkce, která opouští vaše zařízení, tak činí přímo k příslušné službě třetí strany, nikdy přes server OuSuisJe.
