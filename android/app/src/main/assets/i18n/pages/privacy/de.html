Datenschutz

Was gesendet wird, an wen, und in welchem Fall.

Das allgemeine Prinzip

OuSuisJe hat keinen eigenen Anwendungsserver: Es werden keine Standortdaten gesammelt, gespeichert oder an einen Server von OuSuisJe übertragen. Die Anfrage zur Standortberechtigung wird nativ von Ihrem Browser verwaltet.

GPS-Ortung

Die Verarbeitung Ihrer Position (Koordinaten, Höhe, Geschwindigkeit, Richtung, Genauigkeit) erfolgt vollständig lokal auf Ihrem Gerät. Es wird nichts irgendwohin gesendet. Diese Funktion funktioniert weiterhin offline, sobald die Website zum Startbildschirm hinzugefügt wurde.

Adresse (umgekehrte Geokodierung)

Wenn Sie eine Adresse suchen, werden die Koordinaten des gewählten Punkts (GPS-Position oder auf der Karte angeklickter Punkt) direkt von Ihrem Browser an den Nominatim-Dienst von OpenStreetMap gesendet, ohne über einen Server von OuSuisJe zu laufen. Diese Funktion funktioniert nicht offline.

Höhe

Der Höhenvergleich sendet auf dieselbe Weise nur die Koordinaten des ausgewählten Punkts — an den Géoplateforme-Dienst des IGN (wenn Ihre Position in Frankreich erkannt wird) oder an Open-Elevation (überall sonst), je nach verwendeter Schaltfläche. Funktioniert nicht offline.

Sehenswürdigkeiten

Die Suche nach Sehenswürdigkeiten in der Nähe (Escape Rooms, Kletterhallen, Gastronomie, benutzerdefinierte Abschnitte…) sendet die Koordinaten des aktiven Punkts an die Overpass-API von OpenStreetMap. Funktioniert nicht offline.

Département, Gemeinde und Mobilfunkmasten

Diese Funktionen erscheinen nur, wenn Ihre Position in Frankreich erkannt wird. Sie stützen sich auf Datensätze (IGN Admin Express, ANFR), die einmal von der Hosting-Infrastruktur von OuSuisJe selbst heruntergeladen und dann auf Ihrem Gerät gespeichert werden. Die daraus resultierende Berechnung (in welchem Département/welcher Gemeinde Sie sich befinden, welche Masten in der Nähe sind) erfolgt danach vollständig lokal, ohne dass Ihre Koordinaten an irgendjemanden gesendet werden. Funktioniert offline, sobald der Download abgeschlossen ist.

Trinkwasser und Toiletten

Ein Datensatz (Trinkwasserstellen und Toiletten in Frankreich, Quelle OpenStreetMap) wird beim ersten Laden der Seite automatisch heruntergeladen, immer von der Hosting-Infrastruktur von OuSuisJe. Die Suche erfolgt anschließend lokal, ohne Übertragung von Koordinaten. Schlägt dieser Download fehl oder löschen Sie ihn, greift die Suche automatisch auf die Live-Overpass-API zurück (gleiche Bedingungen wie im Abschnitt „Sehenswürdigkeiten“ oben).

Niederschlagsradar

Die Anzeige des Radars fragt bei RainViewer die Bilder an, die dem aktuell auf der Karte angezeigten Bereich entsprechen (Koordinaten und Zoomstufe der Ansicht, nicht Ihre GPS-Position). Funktioniert nicht offline.

Besucherzähler

Ein anonymer, aggregierter Besucherzähler (ohne personenbezogene Daten) wird bei jedem Laden der Seite bei einem Drittanbieterdienst registriert.

Teilen

Die Teilen-Schaltfläche verwendet das native Teilen-Werkzeug Ihres Geräts oder kopiert einfach den Link der Website in Ihre Zwischenablage. Dabei werden keine Daten an OuSuisJe übertragen.

Android-App

OuSuisJe existiert auch als eigenständige Android-App. Dort gelten dieselben Prinzipien: kein eigener Anwendungsserver von OuSuisJe, und jede Funktion, die das Gerät verlässt, geht direkt an den betreffenden Drittanbieterdienst, nach denselben Regeln wie oben.

Kurz gesagt: Jede Funktion, die Ihr Gerät verlässt, geht direkt an den betreffenden Drittanbieterdienst, niemals über einen Server von OuSuisJe.
