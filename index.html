Si la localisation GPS est activée, aucune information n'est envoyée à ousuisje.fun : le traitement se fait entièrement en local, sur votre appareil (ce site peut fonctionner comme une application hors ligne si vous l'ajoutez à l'écran d'accueil).

Si le géocodage inverse est activé pour trouver les informations administratives (commune, département, etc.), aucune information n'est envoyée à ousuisje.fun, mais seulement au service Nominatim d'OpenStreetMap (ne fonctionne pas hors ligne).

La comparaison d'altitude interroge le service géoplateforme de l'IGN ou Open-Elevation selon le bouton utilisé, et la recherche de points d'intérêt interroge l'API Overpass d'OpenStreetMap — dans tous les cas, uniquement les coordonnées du point sélectionné sont envoyées, directement depuis votre navigateur, sans passer par ousuisje.fun (ne fonctionnent pas hors ligne).
